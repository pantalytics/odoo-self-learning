Odoo Self Learning

See where your users get stuck, powered by PostHog

A lightweight, privacy-conscious asset module that injects PostHog into the Odoo backend. Dormant until you connect it to Pantalytics.

One button to set up

Press Connect to Pantalytics in Settings, approve in your browser, done. No key to type: the PostHog project arrives in a signed answer from Pantalytics, and nothing is sent before you connect.

Pseudonymous

Users are identified as db#uid, never a name or an email. Each database reports under its own PostHog workspace.

Privacy first

Input text is always masked and autocapture ignores element values. Session replay and text masking are switches on the settings page, per instance.

Zero friction

One backend asset, one settings page. No RPC round-trips: config rides along in the session on every page load.
