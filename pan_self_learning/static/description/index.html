Self-Learning Odoo

Observe → Propose → Approve → Learn

The observation layer of a loop that turns real usage into advice. This module records how your team uses Odoo, powered by PostHog. Proposals and approvals follow in later steps.

Live on install

Ships pre-connected to the Pantalytics EU project. Swap the key or switch it off under Settings → Self-Learning Odoo.

Pseudonymous

Users are identified as db#uid, never a name or an email. Each database reports under its own PostHog workspace.

Inputs always masked

Typed-in text never leaves the browser. Session replay is on by default; visible text can be masked too with one toggle.

Zero friction

One backend asset, one settings page. No RPC round-trips: config rides along in the session on every page load.
